# Archiwum prototypu Godot

`godot/` zachowuje dawny projekt i materiały jako referencję do inspiracji.
Główną grę rozwijamy w `../unreal/FlyingCabFlightLab/`.

Otwieraj `godot/project.godot`, jeśli chcesz obejrzeć stary prototyp. Jego `res://` odnosi się do katalogu `godot/`, więc wewnętrzne ścieżki pozostają takie jak wcześniej.
README i AI_CONTEXT wewnątrz archiwum opisują historyczny stan Godota.

Zachowano oryginalną zawartość 3784 plików projektu i materiałów, w tym dawnych eksportów. Z nowego drzewa Git wyłączono 316 plików metadanych macOS (`.DS_Store`, `._*`); pozostają w historii oraz lokalnie. Cache `.godot/` pozostaje lokalny i ignorowany.
